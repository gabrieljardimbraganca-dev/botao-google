# Botão Google com To-Do List

Repositório com dois projetos:

1. **Botão Google** - Botão com redirecionamento para Google
2. **To-Do List** - Aplicativo de tarefas com armazenamento local

## 🚀 Como usar

- Botão: `index.html`
- To-Do List: `todo.html`
